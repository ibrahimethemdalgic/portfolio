# İbrahim Ethem Dalgıç — Portfolio

🇹🇷 [Türkçe README için tıklayın](./README.tr.md)

A personal portfolio website built with plain HTML, CSS, and JavaScript. It presents an about section, a list of skills, a projects showcase, and contact links.

🔗 Live Demo

https://ibrahimethemdalgic.github.io/

## 🛠️ Built With
- HTML5
- CSS3 (custom properties, responsive design, scroll animations via `IntersectionObserver`)
- Vanilla JavaScript (no frameworks or libraries)
- Fonts: [Inter](https://fonts.google.com/specimen/Inter) & [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)

## 📁 Project Structure
```
├── index.html
├── css/

├── JavaScript/

├── images/
│   └── profil.jpeg
```

## ✨ Features
- Responsive layout (mobile & desktop)
- Collapsible sidebar navigation
- Smooth scroll to sections
- Scroll-triggered fade-in animations
- "Back to top" button
- Downloadable CV
- Respects `prefers-reduced-motion` for accessibility

## 🚀 Getting Started
Clone the repository and open `index.html` in your browser — no build step or dependencies required.

```bash
git clone https://github.com/ibrahimethemdalgic/your-repo-name.git
cd your-repo-name
```

Then simply open `index.html` in a browser (or use a tool like VS Code's Live Server extension).
